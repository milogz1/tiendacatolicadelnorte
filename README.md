# Soporte Remoto TI - Proyecto U1

Sitio web para servicios de soporte remoto especializado en TI. Desarrollado como proyecto académico para la materia "LENGUAJES DE PROGRAMACIÓN PARA LA WEB".

## Características

- **Diseño responsive** que se adapta a diferentes dispositivos
- **Sistema de cotizaciones** con cálculo automático de subtotales
- **Base de datos local** para almacenar cotizaciones
- **Generador de cuentos personalizados**
- **Formularios interactivos** con validación
- **Integración con Google Maps**
